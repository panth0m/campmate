# CampMate Australia

Cloudflare Pages-ready affiliate-style camping gear comparison site.

## Included
- 300 products
- bundled local SVG product images (no broken remote image URLs)
- 6 category hero images
- product compare pages with 7 store links each
- eBay live route at `/api/ebay-search`
- 6 SEO guides

## Cloudflare variables for live eBay pricing
- `EBAY_CLIENT_ID`
- `EBAY_CLIENT_SECRET`

If you do not set them, the site still works and shows store search links.
